One line, at most 160 characters, roasting the smart fridge — a fridge with an
internal camera that replays your midnight cake footage every time you open
the door, like a disappointed parent with a projector.

## How it works

`main.py` (standard library only) copies the stored roast in `entry.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, deterministic.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
